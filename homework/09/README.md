## Ellenőrzőlista
- [x] **Iteráció:** a prototípus a 8. házi tesztjei alapján iterálva (1. iteráció: L1–L5), majd a 2. kör alapján újra (oszlopfejléc, az időveszteség viszonyítási alapja).
- [x] **Döntési napló:** 7 bejegyzés (D1–D7), mindegyikben bizonyíték, hipotézis, módosítás, elvetett alternatíva, várt hatás és nyitott kérdés.

- [x] **Megosztható Figma-link.**
- [x] **Külön mini design system oldal:** 10 komponens, használati szabályokkal és előfordulásszámmal.
- [x] **Gomb:** Elsődleges, Másodlagos, Szöveges link × Alap, Rámutatás, Fókusz, Letiltott, Betöltés.
- [x] **Beviteli mező:** Alap, Fókusz, Kitöltött, Hiba, Letiltott.
- [x] **További elemek:** Legördülő szűrő, Jelölőnégyzet, Stat kártya, Session sor, Kanyar sor, Állapotsáv, Oldalsó menü, Grafikon.
- [x] **Átadásra előkészített képernyő:** 02 Session-összefoglaló, 5 állapotban, Dev Mode-annotációkkal és számozott annotációkkal, változónevekkel, elfogadási kritériummal.
